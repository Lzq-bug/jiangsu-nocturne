# 清名桥 · 运河灯河

「清名桥 · 运河灯河」是一个纯浏览器端运行的无锡古运河夜景三维全景。整条场景——单孔石拱桥、两岸枕河人家、横巷与河埠、灯船与荷灯、水面倒影——全部由代码在运行时生成：仓库里没有任何模型文件、贴图文件或音频文件，`src/textures.js` 在 canvas 上现画瓦垄木纹石缝粉墙，`src/architecture.js` 用 2D 轮廓挤出桥身。three.js r160 以仓库内置（`vendor/`）方式提供，页面加载后不再发起任何网络请求，打包出的单文件 HTML 双击即可打开。

坐标单位为米。古运河沿 Z 轴展开（−Z 下游、+Z 上游），水面 `y = 0`；清名桥沿 X 轴跨河；西岸（`x < −11`）是南长街，东岸（`x > 11`）是南下塘。场景用一个固定随机种子（`src/kit.js` 的 `seed = 20240921`）程序化布置，每次打开看到的是同一条河。

## 画面主线：一桥两岸 · 灯船穿桥

- **一桥**：清名桥按公开资料的实尺建模（全长 43.2 m、桥面宽 5.5 m、通高 8.5 m、桥孔跨度 13.1 m），拱券取半圆，桥面是一条反穹圆弧，从孔顶 8.5 m 落到两岸 2.2 m，桥头两端各接 17 级台阶。
- **两岸**：西岸连排枕河房（临水一面是后门、长窗、美人靠，另一面开门面街），东岸围墙夹横巷，形成「水陆并行、河街相邻」的对照。
- **灯河**：一盏盏檐下灯、巷灯、埠灯、桥灯组成暖色密度场；灯船从下游御码头解缆，穿过桥洞，券腹的七盏灯把整孔内壁染黄；河灯（荷灯）顺水漂向下游；`src/water.js` 的加法混合光柱把每一盏岸灯拖一条到水面上，倒影系统再把整座街区镜像一次。

主线落点是三个机位的连续叙事：`shuibu`（河埠头低视角）→ `qiaodong`（桥洞看船穿出来）→ `gongding`（站到拱顶看运河怎样拐这一环）。

## 快速开始

需要 Node（`package.json` 声明 `engines.node >= 18`）与一个支持 WebGL2 的桌面/移动浏览器。无安装步骤，无依赖下载。

```sh
# 1) 本地预览（ES Module 不能用 file:// 打开，必须走 http://）
node tools/serve.mjs 8795
#    打开 http://127.0.0.1:8795/index.html
#    注意：不带端口参数时 serve.mjs 监听 8765，而 tools/shoot.mjs 固定访问 8795，
#    要跑截图自检请显式给端口：node tools/serve.mjs 8795

# 2) 打包成单文件（脱离服务器，双击即开）
npm run build
#    产出 dist/清名桥运河灯河-3D夜景.html
```

操作：左键拖动（全景模式转头 360°／自由模式环绕）、右键或两指拖动（平移）、滚轮或捏合（全景调视野角、自由推拉）、点击发光热点=移动到该机位并打开解说、底部景点条直接切换 7 处机位。键盘 `A`/`D` 上一/下一景点，`Space` 自动巡览，`P` 切换模式，`F` 全屏，`H` 帮助，`Esc` 关闭面板。

## 脚本表

| 命令 | 实际执行 | 说明 |
| --- | --- | --- |
| `npm run dev` | `node tools/serve.mjs` | 零依赖静态预览服务，默认端口 8765（第一位置参数或 `PORT` 环境变量可覆盖；第二位置参数换站点根目录，如 `node tools/serve.mjs 4173 dist` 只发打包产物），响应头 `no-store` 以免改完看到旧文件 |
| `npm start` | `node tools/serve.mjs` | 同上 |
| `npm run build` | `node tools/build-single.mjs index.html src/main.js "dist/清名桥运河灯河-3D夜景.html"` | 把 ES Module 图折成一个自执行函数，内联 `styles.css`，移除 importmap，产出可离线双击的单文件 |
| `node tools/shoot.mjs [id…] [--fmt=png\|jpg] [--size=w,h] [--settle=ms] [--port=9334] [--out=shots]` | 直调 Edge | 一次无头会话把所有机位走一遍，输出 `shots/<id>.<fmt>`；需先在 8795 起服务 |
| `node tools/cdp-probe.mjs <port> "<expr>" [url子串]` | 连已开的 Edge 调试端口 | 抓 console/异常并求值表达式，附带 `renderer.info`（draw call、三角面、几何/纹理/program 数） |

`tools/build-single.mjs` 的三个位置参数都有默认值，其中 outfile 默认沿用系列早期场景的文件名，所以本项目必须像 `package.json` 那样显式传第三个参数。

## 已核实事实与写意边界

这一节是作品的诚实边界，也是页面内「操作说明」弹窗最后一段的展开。判断依据是公开资料；模型是夜景写意重建，不是测绘或考古复原。

### 已核实并按实尺建模

- 清名桥为**单孔花岗岩石拱桥**，全长 **43.2 m**、桥面宽 **5.5 m**、通高 **8.5 m**、桥孔跨度 **13.1 m**。这四个数字直接进 `src/data.js` 的 `BRIDGE` 常量，桥身轮廓与热点全部由它们推出。
- **始建于明万历年间，初名「清宁桥」**；**清道光年间避宣宗旻宁讳改称「清名桥」**；**康熙八年由无锡县令吴兴祚主持重建**。这段沿革写在 `gongding` 机位的解说正文里。
- **空间格局**：运河在这一带近南北向，**西岸南长街、东岸南下塘**，「**水陆并行、河街相邻**」——即街与河平行、河街相邻布置。这决定了 `BANK.west/east` 的分带（驳岸—河沿步道—枕河房—横巷—主街）与两条岸线的气质差别。

### 明确属于写意添加（不是考据）

以下每一项都是为夜景构图做的取舍，读者不应把它当成实物现状：

- 这一段运河取 **22 m 面宽**（`RIVER.halfWidth = 11`）与 2 m 岸壁高——不是实测河宽。
- **桥面台阶级数**（两端各 17 级）、**拱脚标高**（`springerY = 1.0`）与拱券取半圆的做法。
- **桥洞通航净高**：为了让灯船真的穿得过去而抬高，实际此孔现状通航条件并非如此。
- **桥面石栏与河埠头石阶的形制**：样式为通用作法，非实测构件。
- 券面「**清名桥**」石额，以及那副拟作楹联「**一虹收尽千家火 / 双岸分开万里船**」的文字——**文字为拟作，不代表实物题刻**；牌坊题额「水弄堂」与埠头题额「御码头」的写法与位置同样属写意。
- **灯船与荷灯**：参考的是运河夜游的今昔观感，不是考据复原。
- **御码头**这一处埠头及其四角灯杆、等客亭。
- 远处**塔影天际线**：一笔写意，不指实某座古塔。
- 两岸屋宇的层数与进深、横巷位置、`ALLEY_W/E` 与 `WHARF_W/E` 的具体点号，都是构图分配。

### 技术上同样要说清

`lanterns.js` 里保留着 `QUAY_PATHS` 与 `quayBridgeAt`（注释提到秦淮、文德桥），`water.js` 的水面 mesh 名为 `qinhuai-water`、倒影着色器缓存键为 `qinhuai-wobble`——这是框架代码从同系列前一场景复制过来留下的标识，本场景实际不使用它们（`props.js` 会传入自己的 `WALK_PATHS` 与 `deckWalk`）。

## 部署方式

零后端、零网络请求，三种用法任选：

1. **单文件分发**（推荐给评委/同学）：`npm run build` → 把 `dist/清名桥运河灯河-3D夜景.html` 单个文件发出去，双击即在本地打开，`file://` 下也能跑（打包器已把 importmap 折成内联注册表）。体积主要来自内置的 three.js（`vendor/three.module.js` 约 1.2 MB）。
2. **静态托管**：直接把整个目录扔到任意静态站点/Nginx/GitHub Pages。只要保证 `.js` 以 `text/javascript` 返回且保留 `type="importmap"`（`tools/serve.mjs` 的 MIME 表就是这么做的）。
3. **本地服务**：`node tools/serve.mjs [端口] [站点根目录]`，只绑定 `127.0.0.1`，并拒绝跳出站点根目录的路径；例如 `node tools/serve.mjs 4173 dist` 就只发打包产物那一个目录。

界面与文字全部内置，不需要外网字体或图片 CDN；中文渲染依赖系统 CJK 字体（详见 `docs/ASSET_LIST.md`）。

## 校验方式

改完代码用无头 Edge 复核，流程写在 `docs/TECHNICAL_GUIDE.md` 的「调试深链与无头工具」一节：`node tools/serve.mjs 8795` + `node tools/shoot.mjs`（逐机位出图到 `shots/`），或 `node tools/cdp-probe.mjs <port> "<expr>"` 看异常与绘制统计。截图深链为 `#bare&station=<id>`，只留画面、隐藏 HUD 与热点环。
