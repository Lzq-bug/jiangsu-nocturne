# 连岛·开渔夏夜 — 模块契约（唯一真源）

真源文件（**不要修改**，所有模块按它们实现）：`src/layout.js`（几何常量）、`src/tide.js`（潮位数学）、`src/data.js`（机位与文案）、`src/main.js`（装配与调用点）。
参照工程：`D:\场景\santai-huaxin\src\*.js`（同一套引擎骨架，写法/注释密度/命名照它来）。

## 0. 全局约定
- 坐标：+X 东，+Z 南，y=0 = 平均海面。陆在北（-Z）、海在南（+Z）、西大堤与港池在西北。
- 单位米，写意尺度，非测绘。
- **潮位 `level`（米，约 -1.65~+1.65）与场景时刻 `hour`（24 小时制浮点，可 >24）由 main.js 每帧算出并作为参数传入各模块**。任何模块不得自己起时钟、不得 import main.js。
- 禁止循环 import（build-single.mjs 会直接抛错）。允许的依赖方向：
  `layout / tide / data` → 无依赖；`kit` → textures；`environment` → kit,textures,layout；
  `architecture`,`props`,`water`,`interiors`,`portals`,`kaiyu` → kit,textures,environment(只读函数),layout,tide,data；
  `ui` → data；`main` → 全部。
- 所有 geometry/material 走 `kit.js`；程序化贴图一律 Canvas 生成在 `textures.js`，带 memo 缓存。
- 夜景发光体用 `glow()`（unlit + toneMapped=false）喂给 UnrealBloom。

## 1. kit.js（A 组）
必须保留并导出：`PAL, rgb, rand, rr, glow, lit, M, initMaterials, box, mesh, registerOccluder, declutter, stringPath, figureGeo, plaqueMesh, railingGeo, pillarGeo`
新增海洋/渔港构件（签名固定）：
- `hullGeo(len, beam, depth)` → BufferGeometry，尖底渔船船体（含舷内空腔，够一个人才行）
- `mastGeo(h, r)` → Group：桅杆 + 横桁 + 索具线
- `tetrapodGeo(size)` → BufferGeometry：防波堤扭王字块（四头连环，允许用 3 个胶囊/圆环近似）
- `umbrellaGeo()` → Group：遮阳伞（布面 + 中杆），可 `scale` 收拢
- `rockGeo(r, detail)` → BufferGeometry：海蚀基岩块（噪声扰动，确定性）
- `flagGeo(w, h)` → BufferGeometry：三角渔旗（顶点带 uv.x 便于波浪 shader）
- `concreteBlock(w, h, d)` → Mesh：码头混凝土块
- `instanced(geo, mat, list)` → InstancedMesh：`list` 为 `{p:[x,y,z], r:[rx,ry,rz], s:[sx,sy,sz]|number}[]`
- `figureGeo()` 复用参照工程（夜客用）
`PAL` 键：`ink, night, moonWhite, star, sand, wetSand, rock, reef, hull, hullTrim, rope, net, rust, steel, glass, lanternWarm, harborGold, navGreen, navRed, navWhite, foam`
`initMaterials()` 里必须建好 `M.sand, M.wetSand, M.rock, M.hull, M.plank, M.rope, M.canopy, M.concrete, M.metal, M.glass, M.net`。

## 2. textures.js（A 组）
`softGlow, sand, wetSand, rock, reef, foam, hull, plank, rope, net, canopy, concrete, rust, sign(text, opts), steleFace, beaconFlame, starField, moonHalo, fogSheet, flagStripe`
全部沿用参照工程的 `canvas()/tex()` 写法与 memo。

## 3. environment.js（B 组）
导出函数：
- `shoreAt(x)` → 平均潮位处岸线 z（对 layout.COAST 做平滑插值）
- `shoreZat(x, level)` → 当前潮位的水线 z（大沙湾/苏马湾按 BEACH.slope 反解，岬角处按 HEADS 抬升）
- `terrainH(x, z)` → 连续高程：南向海床下沉、岸线以上滩地、后缘台地 rim、RIDGE 岛丘、BASIN 港池洼地（切到 -cut）、MAINLAND_LAND 西侧陆地、海峡低于 0
- `slopeAt(x, z)` → Vector2
- `zoneAt(x, z)` → `'sea' | 'sand' | 'rock' | 'platform' | 'hill'`
- `MOON_DIR`（Vector3，月光方向）、`GEO`（导出给水的色）
- `buildEnvironment(scene)` → `{ sky:{mesh,stars,update}, trees:{group}, range:{group}, mist:{group}, gulls:{mesh,group}, lights:[hemia, point, ...], setMist(bool), setGulls(bool), startle(x,z), update(t, dt, hour, level) }`
  - `lights[1]` 必须是会被相机跟动的 PointLight（main.js 每帧给它设 position）
  - `update` 内按 `hour` 算 dayness：19.4 起黄昏余晖（西天微亮）→ 22 后全黑 → 4.8 前后东天先亮一线 → 5.6 开渔前的灰蓝；同时抬升月/金星高度、调整 fog 色与 `sky` 渐变色
  - 远景 `range.group` = FAR_RANGE 云台山剪影；`stars` 用 `starField()`
  - 海气/雾 `mist.group` 要贴着水面与滩地

## 4. water.js（C 组）
- `class WaveRings`：`emit(x, z, t0, amp)`、`update(t)`、`get list()`；最多 8 圈，速度参照 CHIME.sustain
- `class Reflections`：`{ root, enabled, add(obj), update(t, level) }`（倒影面必须跟着 `level` 起落）
- `class LightColumns`：`{ mesh, update(t, swell, gain) }`，光柱落在港池与湾口水面上
- `buildWater(scene, rings)` → `{ mesh, foam, update(t, swell, level), setFrost(bool) }`
  - 海面 = 一个大 plane，y 每帧设为 `level`；顶点 shader 叠涌浪 + 长浪，`swell` 为倍率
  - 与地形求交的水线泡沫：在 fragment 里用 `uTide` 与传入的高度图/`shoreAt` 近似，或顶点着色器按 `terrainH` 采样生成泡沫带（选一种实现，注释写明）；低潮时港池与外海连通、退水后露出潮沟纹理
  - 深水色用 layout.SEA 的 deep/mid/shelf

## 5. architecture.js（D 组）
导出 `LAYOUT`（运行期回填，形状固定）：
```
LAYOUT.chime = { pos: Vector3, pivot: Object3D|null, lamps: [] }   // 灯塔灯室/回廊的灯组，潮信声源
LAYOUT.tower = { pos: Vector3, top: number, door: Vector3, gallery: Vector3 }
LAYOUT.walk  = { curve: CatmullRomCurve3|null }                    // 栈道，点的高程含栏面
LAYOUT.dyke  = { curve: CatmullRomCurve3|null, lamps: [] }
LAYOUT.quay  = { pts: [[x,z]...], top: number, bollards: Vector3[] }
LAYOUT.stele = { pos: Vector3, door: Vector3 }
LAYOUT.pavilion = { pos: Vector3 }
LAYOUT.berth = { door: Vector3 }
```
`buildQuarter(scene, env)` → `{ group, dyke, harborLights, anchors:{ quay, tower, lamp, pier }, chime, setStrip(v) }`
必须建的实体：西大堤（堤顶 +9、宽 12、每 34 m 一灯、外坡 ARMOUR 护面块）、港池码头 QUAY 与系缆桩、BREAKWATER 与灯塔 LIGHTHOUSE（h 26.5，灯室在 focal 22，6 秒闪光，闪光体注册进 `LAYOUT.chime.lamps`）、BUOYS 口门灯桩、BOARDWALK 栈道与栏、PAVILION 观日亭、STELE 刻石保护亭（岩面 + 可辨字口 + 围栏）、BEACON 烟墩、VILLAGE 无名灯窗楼群、HUTS/LOOKOUT 瞭望塔、停泊区浮筒与防浪堤。`setStrip(v)` 调堤灯/栈道灯/港内灯串的整体亮度。

## 6. props.js（E 组）
`buildProps(scene, columns, anchors, quarter)` →
```
{ crowd:{mesh, update(t,dt,count,camPos)},
  strings:{group, uni:{uOn:{value}}, update(t), wave(x,z,t0,hue,amp)},
  umbrellas:{group, update(t, level)},
  spray:{mesh, update(t, level)},
  flags:{group, update(t, dt)},
  fleet:{group, update(t,dt,scale,level,hour), moored(i), lead(), depart(hour), boats:[...]} }
```
- `fleet`：按 layout.BERTHS 排 5×11 艘，吃水随 `level` 起落、缆绳与桅灯同步；`depart(hour)` 让船按 CHANNEL 顺序解缆驶向口门（`hour` 之后 12~40 秒内陆续走），走完后仍在 `group` 里
- `umbrellas`：FIELD 内阵列，`open` 比例由 UMBRELLAS.open 决定；`update(t, level)` 只做强风微颤（不随潮位收拢，但前排被淹时伞脚浸在水里）
- `crowd`：WALK 路径 + 滩上散布，`figureGeo()` 实例化，人形带暖色灯火反射
- `spray`：浪击礁盘（HEADS、SHEEP、ARMOUR 处）的粒子，位置随 `level` 变
- `flags`：船尾与码头旗杆，shader 里做波浪

## 7. kaiyu.js（F 组）
`class Kaiyu`：构造参数 `{frame, rings, props, env, position, onCount, onRelease}`（frame = `quarter.chime`）
- `one(t)`：报一更 → `rings.emit`、`props.strings.wave`、`env.startle`、Web Audio 合成汽笛/雾号（五声音阶取 data.WATCH_TONES 的 semitone）、`count++`，返回对应 WATCH_TONES 项
- `ringAll(t)`：按 CHIME.interval 连报 5 更；末了调 `onRelease()`（→ main 里 `props.fleet.depart(hour)`）
- `stop()`、`update(t, dt, camPos)`（含 `dim` 输出，语义同参照工程 Huaxin）、`addFlashTo(scene)`（灯塔 6 秒扫光）、`hits`、`rings` 字段可被 main.js 直接取用

## 8. interiors.js / portals.js（F 组）
- `buildInteriors(scene, boat)` → `{ update(t, level) }`；两处：灯塔灯室（旋梯顶、透镜与扫光、口门外是海）、渔船甲板/驾驶室（随船动，`boat` 为 `props.fleet.lead()`，可能为 null，必须判空）
- `buildPortals(scene, rig, boat)` → `{ space, nearest(p), use(p), pick(ndc, camera), update(t, camPos, level), onSpace }`；两处门：`tower`（灯塔门 `LAYOUT.tower.door`）、`boat`（跟随船的 `LAYOUT.berth.door`）。船的门口高程要加 `level`。

## 9. controls.js / hotspots.js / ui.js（G 组）
- `controls.js` 基本照抄参照工程（CameraRig：`mode, pos, target, dist, theta, phi, yaw, pitch, fov, travel, autoRotate, onTap, update(dt), goTo, goToOrbit, setFov, setDist, nudge, poseFor`）；把 `nudge` 的边界改成连岛范围（x:-1750~780, y:1.6~320, z:-1500~1400）
- `hotspots.js` 照参照工程（`Hotspots` 类：`labelsVisible, exteriorShown, current, setCurrent(id), update(camera, t, size), pick(ndc, camera), grp`），热点环的 HTML 标签文案用 `s.short`
- `ui.js` → `createUI({stations, onChange, onSelect, onMode, onTour, onShot, onReset, onStep, onBell})`，返回：
  `setMode(m), setActive(id), showInfo(s), hideInfo(), setBell(count, ringing, watch), bellNote(text), setFps(fps, low), setCompass(deg), perfHint(text), loading(p, text), loaded(), setClock(hhmm, tideWord, level, nextTurnH)`
  - 滑杆 key 与 DOM id 一一对应：`speed(s-speed/v-speed, 1..60, 默认 14, 显示「×」倍率或「分/秒」)`、`swell`、`crowd`、`fleet`、`strings`、`glow(0..180 → onChange 传原值，main 里 /100)`
  - 开关：`c-reflect, c-labels, c-mist, c-gulls, c-tour, c-quality`
  - 键盘沿用：B 报一更、N 轮满五更、Esc 止、A/D 机位、Space 巡览、P 模式、F 全屏、H 帮助、E 进门
  - 新增「潮信卡」（#bell 区）：显示第几更、五更进度条、当前 `#watch-name` 文案
  - 新增「潮位标尺」HUD（#tide 卡）：`#tide-time`(hhmm)、`#tide-state`(tideWord)、`#tide-value`(level 米，2 位小数)、`#tide-bar`（按 GAUGE 填色，标出高/低潮线）、`#tide-next`（距转流 x.x 小时）
- 同组负责重写 `index.html`（标题「连岛 · 开渔夏夜 3D 夜景全景」，importmap 与 `<script type="module" src="./src/main.js">` 保持）与 `styles.css`（配色改为海州湾夜：青黑、月光白、港内橘金、口门红）。index.html 必须含 main.js 用到的全部 id：`stage, grain, loader, loader-step, loader-bar, panel, panel-body, panel-toggle, stations, info, info-title, info-era, info-lead, info-body, info-tags, info-close, help, help-close, fps, btn-help, btn-shot, btn-full, btn-reset, btn-defaults, btn-bell-one, btn-bell-ringer, btn-bell-stop, btn-<...>, mode-pano, mode-free, compass, compass-rose, perf-hint, bell, bell-strike, bell-fill, watch-name, bell-note, tide, tide-time, tide-state, tide-value, tide-bar, tide-next`
