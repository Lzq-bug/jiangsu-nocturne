## 3. 审计覆盖的三种视角

本项目刻意不只用一种视角审自己的美术：

1. **盲审** —— 不给风格提示，只问「这张牌画的是什么、能不能读出来」，用于验证叙事可读性。
2. **开放联网审** —— 主动联网检索是否存在可感知的具体作品联想，用于发现无意识趋同。
3. **指定对照审** —— 指定「原神 · 月谕圣牌」作为最需要避开的参照系，逐项核查禁用元素
   （星云 / 大型轨迹圆环 / 漂浮物 / 剧院盒式空间 / 相框墙 / 发光轨道 / 整屏 bloom 等）。

三种视角的结论都写进了 `docs/CARD_ART_STYLE_LOCK.md` 的禁用清单，
成为后续 70 张的硬生产规则。

## 4. 审计真正改变过什么（可追溯）

审计不是走过场，本项目的审计结论直接产生了这些改动：

| 来源审计 | 产出 |
| --- | --- |
| 开放联网审 / 指定对照审 | `CARD_ART_STYLE_LOCK.md` 禁用元素清单 |
| 第一次中期抽检（P2） | 3 张牌 polish 提交 `4ac6270` |
| 第二次中期抽检（防模板化质疑） | `CARD_ART_MOTIF_BUDGET.md`（母题配额表）+ 窗口 #3 五条硬规则 |
| 第三次中期抽检（宫廷同族感） | `COURT_CARD_ANTI_TEMPLATE_PROTOCOL.md`（六维互异协议） |
| Final Art Audit | `FINAL_ART_FREEZE = YES`，78 张封板 |

其中宫廷协议的建立过程是有记录的**真实失败 → 修复 → 复检通过**：
窗口 #4 内部 `INTERNAL_COURT_GATE_01`（15 项检查）判定
**宝剑宫廷「白色楔形族」FAIL** —— 侍从/骑士/王后/国王四张初稿都用大面积高不透明度「云隙冷光楔」，
96px 下一律读作「白旗 / 船帆」，构成 4 张同骨架族（违反协议 §31）。
修复方式：四张光源全部收窄为缝隙 / 细月牙（面积 < 15%、不透明度 ≤ 0.55），
且四张光缝形态与位置互异（窄横缝 / 斜切锋线 / 双云夹缝 / 左上月牙），同时加强人物轮廓光。
复检 PASS 后才放行 Batch 17。同批还打回并修复了「圣杯王后礁石误读为大球」。
详见 `docs/ART_PRODUCTION_SESSION_04_REPORT.md` §13 与 §13.1。
