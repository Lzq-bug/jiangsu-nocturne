制作方式的可验证痕迹：

- 每张 SVG 都是可读的矢量指令（`<path>` / `<g>` / `<clipPath>` / `<pattern>`），
  不是被嵌入的位图，也不含 base64 图像数据；
- 资产总体积 **375,801 字节**（约 367 KB / 78 张），单张平均约 4.8 KB——
  这个体积量级只可能来自手写矢量，不可能是任何位图或 AI 生成图；
- `vite.config.ts` 设 `assetsInlineLimit: 0`，构建后 78 个 SVG **独立发射为文件**，
  可逐张审计。

## 3. 审计过程（事实）

共执行 **8 轮**视觉审计，覆盖三种不同视角：

1. **盲审**（不给风格提示，只问「画的是什么、读不读得出来」）
2. **开放联网审**（主动检索是否存在可感知的具体作品联想）
3. **指定对照审**（指定「原神 · 月谕圣牌」为最需避开的参照系，逐项核查禁用元素）

审计不是一次性的：在 8 / 24 / 40 / 56 / 78 五个覆盖节点均有检查，
其中 24 / 40 / 56 三次为**独立中期抽检**，结论均为 Gate B（带新约束继续）。

**Court Gate 曾真实 FAIL**：
窗口 #4 内部 `INTERNAL_COURT_GATE_01` 判定宝剑宫廷四张初稿构成「白色楔形族」同骨架
（96px 下均读作白旗 / 船帆），**FAIL 并自行打回重做**；收窄光源并互异化后复检 PASS 才放行。
同批另一张「圣杯王后礁石误读为大球」同样被打回修复。
这是本项目流程约束真实生效的证据——Gate 不是装饰性的。

**78 Final Audit = PASS / Gate A**，随后 `FINAL_ART_FREEZE = YES`。

审计索引见 `docs/ART_AUDIT_INDEX.md`；冻结声明见 `docs/FINAL_ART_FREEZE.md`。

## 4. 形成的原创视觉资产体系（事实）

本项目在制作过程中形成了一套自有的、可复用的视觉语言，它不依赖任何外部作品的视觉资产：

- **牌面结构**：月窗铭号（新月牌匾 + 罗马数字）/ 星轨饰带 / 秘仪画窗 / 真名带 / 火漆星印，
  全部由 `src/ui/CardArt.tsx` 与 `src/ui/cardShapes.ts` 程序化生成；
- **牌型轮廓**：月章 22 种异形轮廓（倾斜 / 台座阶数 / 翼形 / 顶部形 / 侧边形），
  星签 4 种花色专属轮廓——不是统一矩形圆角卡；
- **技法取向**：铜版蚀刻式线稿 + 排线阴影 + 珐琅点彩 + 单点叙事光源；
- **物质感优先**：纸张 > 金属（旧银 / 黄铜）> 珐琅 > 墨线 > 手绘痕迹；
- **术语体系**：宵月秘藏 / 月章 / 星签 / 魔女阁 / 启封 / 封缄 / 魔女手记 /
  星屑 / 观星台——全案自有词汇，不使用任何官方术语；
- **世界观**：窗外是星夜，室内是魔女会的旧观星书房（见 `docs/ENVIRONMENT_VISUAL_SYSTEM.md`）。
