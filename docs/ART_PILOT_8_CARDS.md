# ART_PILOT_8_CARDS · 8 张正式试制牌设计记录

> 实现方式：全部为**手工程序化 SVG**（铜版蚀刻线稿 + 排线阴影 + 珐琅点彩 + 单点叙事光源）。
> 本环境未启用 AI 位图生成；按任务书 §14.B 以"比程序化纹章高一个视觉层级"为目标手工绘制。
> 每张独立文件、只含画窗内容，牌框由 `ui/CardArt.tsx` 矢量层负责。

## A1 · 0 愚者 The Fool

- **为什么选它**：人物牌 + 开放空间 + 明亮构图 + 初始牌，测试"亮调不崩体系"。
- **构图**：右上崖体斜切，旅人剪影正跨出崖沿（重心偏右下）；左侧大面积晨空留白；远山两叠、雾带两道。
- **主体**：跨步旅人剪影（杖挑行囊）、先行的小犬、道旁白玫瑰。
- **光源**：两处同源暖金——右中崖后初升日弧（主）+ 左上晨星（辅），同为一族 #E3C27E。
- **主色 / 辅色**：晨金 #E3C27E / 旧银 #C7CEDD。
- **象征物**：断崖（未知）、行囊（过往）、犬（警示与陪伴）、晨星（指引）。
- **禁用元素**：星云、宇宙浮空。
- **与同系列差异**：全组最亮的牌；唯一"开阔地平线"构图。
- **资产**：`src/assets/cards/major/major-00-the-fool.svg`（5.9KB）
- **实现结构**：径向渐变纸底 + 云朵排线 pattern + 剪影填充(#0B0F20)+银缘 + 日弧半悬 + 小径光楔。
- **开发调整**：初版旅人比例过大，缩小并右移以留出"迈出的那一步"负空间。

## A2 · VI 恋人 The Lovers（高风险牌）

- **为什么选它**：唯一实际见过原作参考的牌，必须证明同名不同物。
- **构图**：垂直对称双轴——两条虚线星轨各自从地平升起，顶端各悬四芒星（**两星不相触**）；中央双生蔷薇共根而立，两茎 S 形上升、两花相向倾斜；花间一粒光隙。
- **主体**：共根双生蔷薇（根系如手稿解剖图外露）。
- **光源**：两花之间的蔷薇色光隙（唯一光点）+ 两个花心小红点。
- **主色 / 辅色**：蔷薇 #C4526A / 旧银。
- **象征物**：同根双生（关系的根）、未触的花（选择尚在进行）、星轨（两条命运线）、根部相扣而不重叠的双环（契约）。
- **禁用元素**：剧院盒、相框墙、乌鸦、枯枝、共舞人物、红幕、飘带、拥抱姿态。
- **与同系列差异**：唯一"植物学图谱"式构图；唯一以负空间（光隙）为光源的牌。
- **资产**：`src/assets/cards/major/major-06-the-lovers.svg`（5.5KB）
- **实现结构**：花瓣以同心圆弧手绘螺旋（非符号字体）、根系贝塞尔、pattern 排线地下。
- **IP Similarity Risk Notes**：
  1. 原作主体是"人物共舞+相框+乌鸦的舞台盒"→ 本作**无人物**，主体是植物；
  2. 原作色彩为红幕暖盒 → 本作是靛底银线+单点蔷薇光；
  3. 原作空间是"盒内" → 本作是"纸上植物图谱"；
  4. 关系表达从"相拥"改为"共根未触"，语义层也已区隔；
  5. 唯一共享者是塔罗公共语义（结合/选择）。

## A3 · XIII 死神 Death

- **为什么选它**：暗色高反差牌，测试"黑暗不落俗套、不血腥化"。
- **构图**：一条镰刃弧光横贯作地平线（左低右高），白马沿刃脊缓行；刃下一排黑玫瑰；地平线后透出一线曙光。
- **主体**：白马剪影（亮部）+ 黑玫瑰田（暗部）。
- **光源**：地平曙光橙线 #E08A4C（每朵玫瑰花心有一粒同色小点呼应）。
- **主色 / 辅色**：曙光橙 #E08A4C / 玄黑 #0A0814。
- **象征物**：镰刃=时效收割、白马=从容 through、黑玫瑰=告别、曙光=门后的早晨。
- **禁用元素**：骷髅、血、鬼影、哥特教堂俗套。
- **与同系列差异**：全组对比度最高；唯一"地平线贯穿"构图。
- **资产**：`src/assets/cards/major/major-13-death.svg`（6.0KB）
- **开发调整**：白马初版马鞍细节过多，删至剪影三笔，保住缩略图可读。

## A4 · XXI 世界 The World

- **为什么选它**：大场景 + 环形象征，测试"圆环不宇宙化"。
- **构图**：中央黄铜子午环（椭圆三重）框住一张刻绘世界图谱盘（经纬+抽象大陆+盘心小舞者）；桂冠两枝自底合抱、顶部一小结；四角四元素小徽记；底纹为手稿网格。
- **主体**：图谱盘+舞者剪影。
- **光源**：纸面烛照暖晕 #E9D9A8（低强度居中），黄铜环零辉光。
- **主色 / 辅色**：黄铜 #B28C4F + 淡金 #E9D9A8 / 手稿灰 #8A93AD。
- **象征物**：星盘（秩序的仪器）、图谱（完整的世界）、桂冠（礼成）、四徽记（四元素齐备）。
- **禁用元素**：星云、发光环、悬浮人物/卡牌、宇宙舞台。
- **与同系列差异**：唯一"仪器/图纸"构图；信息密度最高但亮度最低。
- **资产**：`src/assets/cards/major/major-21-the-world.svg`（6.3KB）
- **IP Similarity Risk Notes**：
  1. 环的处理：原作（及其同族表达）是"发光能量环+星云"→ 本作环是**哑光黄铜仪器刻线**，材质与亮度完全相反；
  2. 空间：原作是宇宙空间 → 本作是"档案室挂图/书桌图纸"，背景是手稿网格纸；
  3. 中心人物：原作为悬浮主体 → 本作是盘面上 12px 的刻绘舞者，属图案而非角色；
  4. 色彩：全图无蓝紫渐变，主色为黄铜+淡金纸感。

## B1 · 权杖王牌 Ace of Wands

- **为什么选它**：权杖家族基准 + A 级牌 + 火熜异形适配。
- **构图**：杖自左下斜升向右上，杖顶三焰；新叶三枚自杖身萌发；余烬星点上升；左下坡地两石。
- **光源**：杖顶焰（三层火舌，焰心留白）。
- **主色 / 辅色**：熔橙 #D9814E / 焰白 #E9EDF5。
- **与家族**：确立权杖语汇=上升斜线+烬点+活木；后 13 张沿用。
- **资产**：`src/assets/cards/minor/minor-wands-1.svg`（4.5KB）

## B2 · 圣杯二 Two of Cups

- **为什么选它**：关系牌，测试与「恋人」的区隔（同为"两者"主题）。
- **构图**：双爵相向微倾，两道水弧彼此对斟；上方双月背立、双角间透出青光（近乎合圆）；爵下静水倒影；两岸香蒲。
- **光源**：双月间的青色光隙 #6FC2C9（与恋人"光隙"母题同族但色/形不同：水平近圆 vs 垂直竖隙）。
- **与恋人的区分**：恋人=垂直生长的植物+星轨；圣杯二=水平对斟的器物+水；无植物、无星轨。
- **资产**：`src/assets/cards/minor/minor-cups-2.svg`（4.9KB）

## B3 · 宝剑三 Three of Swords

- **为什么选它**：情绪符号牌，测试"锋利而不血腥"。
- **构图**：两卷云涡围成心形云团，三柄细剑竖直穿落（中剑略前）；雨丝排线；云后一粒四芒星；左上一道冷月薄光楔。
- **光源**：冷月斜辉 + 云后星（痛后仍有的坐标）。
- **主色 / 辅色**：霜钢蓝 #9FB6D9 / 银白。
- **防血腥处理**：被穿的是"云之心"而非血肉；无红色、无液滴，只有雨。
- **资产**：`src/assets/cards/minor/minor-swords-3.svg`（4.7KB）

## B4 · 星币国王 King of Pentacles

- **为什么选它**：宫廷牌 + 人物牌 + 等级升级规则验证（王=城垛冠+微金）。
- **构图**：石木王座上的侧面剪影王，戴三点冠（顶缀星），双手扶大环璧于膝（全牌最亮）；袍褶自肩泻下、袍脚化作田垄；坐侧葡萄藤；左后堡楼剪影。
- **光源**：环璧苔金辉光 #A8B87A（烛照币面）——"王的财富是替未来保管的那一粒"。
- **与家族**：确立宫廷三件套=剪影人物+花色持物+等级冠饰；背景引入堡楼/田垄（星币语汇）。
- **资产**：`src/assets/cards/minor/minor-pentacles-14.svg`（5.2KB）
