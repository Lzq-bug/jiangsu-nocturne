# COMPETITION DEMO FLOW · 比赛现场演示脚本（90 秒）

> 目标：让**完全陌生的观众**在 90 秒内理解三件事——
> **我玩了什么 / 为什么想继续抽 / 抽到以后能干什么。**

---

## 0. 一句话定位（开场前记在心里）

> 《宵月秘藏》是一个**原创塔罗收藏小游戏**：
> 玩观星小游戏拿星屑 → 用星屑启封卡牌 → 收集全套 78 张原创卡面。

配套展示图：`.showcase/competition/competition-01..06-*.png`

## 2. 每段的核心信息（只记这个）

| 段 | 观众必须记住的一件事 |
| --- | --- |
| 主厅 | 玩法是「玩 → 攒 → 启封 → 收藏」，不是纯展示页 |
| 观星台 | 它是一个**真的可玩的小游戏**，不是动画 |
| 星屑 | 星屑是游戏内唯一货币，只用于启封 |
| 启封 | 有仪式感，而且是**玩家亲手翻牌** |
| 揭示 | 结果当场可见：新牌入阁 / 重复转补偿 |
| 魔女阁 | **78 个牌位**的收藏系统，有进度、有筛选 |
| 详情 | 每张牌都有内容，不是一张图 |

## 3. 建议的现场操作（真实点击，不用截图代替）

1. 打开主厅 → 手动指一下「① 玩观星小游戏 → ② 获得星屑 → ③ 启封卡牌 → ④ 收藏 78 张」这一行。
2. 点导航「观星台」→ 点「开始观星」→ **现场真的抓 2–3 颗星**（这是最有说服力的 10 秒）。
3. 结算后点「去启封 →」。
4. 点封缄匣 → 点任意一枚封缄 → 等卡面翻开。
5. 点「前往魔女阁」→ 点任意一张已启封的牌。
6. 滚动看一页魔女手记。

> 演示前建议先玩一局攒够星屑（或直接用本机已有存档），保证第 4 步不会因为星屑不足而卡住。
> 星屑不足时启封匣会显示「星屑不足（需 30 ✦，现有 N ✦）—— 去观星台」，流程不会断。

## 4. 可能的提问与回答

| 提问 | 回答 |
| --- | --- |
| 卡是谁画的？ | 「78 张全部是手写的矢量图形，一牌一个文件，不是素材图、不是 AI 生成图。可以逐张打开看代码。」 |
| 抽卡概率能作弊吗？ | 「不能。结果在你点『开始』的那一刻就已经由引擎算完并写进存档了，扇形选牌只是让你亲手揭晓——规则是诚实的，代码里有注释说明。」 |
| 会一直加东西吗？ | 「已经开发冻结了。现在只接受 bug 修复和展示维护——完成度比功能数量重要。」 |
| 手机上能玩吗？ | 「能，同样的完整流程。截图在 `README-05-MOBILE`。」 |
| 重复的牌怎么办？ | 「重复会转成星屑补偿（+6 ✦），进度不会白费。」 |
| 有 AI 吗？ | 「有一个**完全可选**的星语占卜：不配置也能玩全部核心内容；配置了才会多一段私语。」 |

## 5. 不要做的事

- 不要现场改代码、改存档、开 DevTools；
- 不要展示 `settings` 页里的 API Key 输入框（与核心玩法无关，容易分散注意力）；
- 不要把「78 张卡」说成「78 种玩法」——它是**一套完整的收藏体系**；
- 不要承诺任何未来功能（项目已进入 DEVELOPMENT_FREEZE）。
