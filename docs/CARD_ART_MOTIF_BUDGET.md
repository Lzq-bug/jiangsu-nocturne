# CARD_ART_MOTIF_BUDGET · 高频母题配额表（窗口 #3 建立）

> 目的：第二次中期独立审计判定量产体系 PASS / Gate B——"可以继续，但加入少量新的防模板化流程约束"。
> 本表冻结**剩余 38 张（窗口 #3 起）**对四个高频母题的总配额。配额是**剩余项目总量**，不是每 Batch 配量。
>
> 使用原则（硬规则）：
> 1. 任何新牌使用下列母题，必须在本表"消耗记录"登记：卡名 + 使用理由 + 消耗后余额；
> 2. **不得因为配额尚有余额就刻意消耗**——同样构图能不用该母题解决的，优先不用；
> 3. 最优策略是**能不用就不用**：窗口 #3 结束时允许配额有剩余；
> 4. 超过配额 = 违反本表，视同 STYLE_LOCK 级失败，须打回。
>
> 计数口径（判定标准，避免各批次口径漂移）：
> - **斜坡行旅**：存在"路径/坡道/水道 + 位移中的主体（人或动物）"两个要素。静止眺望者、纯路径无行者记为"部分"，不计入配额但记录在案。
> - **水面倒影**：水面存在可辨认的镜像（人/月/星光/器物）。仅有水纹、水线、池面但无镜像的记为"部分"。
> - **拱门/窗/龛**：画面主体或光源依托建筑开口（拱、门、窗、龛、门架）。纯背景砖石纹理不计。
> - **中央大圆**：以大型圆形结构承担主视觉（≥画窗 40% 高度）。小型附属圆（轮辐、杯口、币面）不计。
