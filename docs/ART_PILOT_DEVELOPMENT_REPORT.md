## 11. 恋人的主动原创化（对照唯一见过的原作参考）

1. 无人物（原作：共舞双人）→ 主体为共根双生蔷薇；
2. 无剧院盒/相框墙/乌鸦/枯枝/红幕（原作核心五件套全部缺席）；
3. 关系语义从"相拥共舞"改为"共根而未触 + 两星不相交 + 相扣不重叠的双环"；
4. 色彩从红幕暖盒改为靛底银线 + 单点蔷薇光隙；
5. 空间从"盒内舞台"改为"纸面植物图谱"。

## 12. 世界的防"宇宙圆环化"措施

1. 环 = 哑光黄铜子午仪刻线（无辉光），不是能量环；
2. 环内是刻绘世界图谱盘 + 12px 舞者剪影（图案，非悬浮角色）；
3. 背景 = 手稿网格纸 + 四角元素徽记（档案室语境，非太空）；
4. 全图无蓝紫渐变；光源是纸面烛照暖晕。
   —— 三项禁配（星云/发光环/悬浮）两两组合均未出现。
