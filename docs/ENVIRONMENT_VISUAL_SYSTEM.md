# ENVIRONMENT VISUAL SYSTEM · 环境视觉系统（冻结规范）

> **本文件是《宵月秘藏》页面级环境背景的冻结规范。**
> 未来任何背景维护都必须遵守本文件；与本文件冲突的改动一律打回。
>
> 实现位置：`src/styles/environment.css`（样式）+ `src/ui/EnvironmentScene.tsx`（场景 SVG）
> 挂载位置：`src/app/App.tsx` 的 `Shell`，按路由给出 `scene` 键。

---

## 1. 核心一句话

> ### 窗外是星夜，室内是魔女会的旧观星书房。

**不是**「人在宇宙里」。

空间本体必须是**实体空间**：有窗、有书架、有桌子、有烛火、有黄铜器具。
星必须出现在**窗外**；月必须属于**夜景**；星盘必须是**桌面上的黄铜器具**。

---

## 2. 空间三层结构

| 层 | 名称 | 实现 | 职责 |
| --- | --- | --- | --- |
| Layer 1 | 远景夜空 | `.env-sky`（纯 CSS radial/linear gradient） | 夜色底 + 低密度星点 + 极弱空气层。**只在窗外与室内空气里存在** |
| Layer 2 | 中景书房 | `.env-room` / `.env-room-m`（程序化 SVG） | 窗棂、书架、天球仪、烛台、桌面、栏杆、羊皮纸、档案标签 |
| Layer 3 | 近景 UI | `src/styles/global.css` | 卡牌、面板、按钮、正文。**永远最高可读性** |

层叠顺序由 CSS 保证：`.env-scene { z-index: 0 }` < `.shell { position: relative; z-index: 1 }`。

## 4. 星空密度与星点规则

| 规则 | 值 |
| --- | --- |
| 桌面端星点数量 | **18 颗**（`radial-gradient` 单层，无 DOM 节点） |
| 桌面端分布 | 集中在画面上部与左右两侧；**中心 36%–64% 区域刻意留空** |
| 单颗尺寸 | 1.0–1.6 px |
| 单颗不透明度 | 0.15–0.50 |
| 窗外星点 | 8 颗（在窗内 clipPath 内，属「窗外」） |
| 移动端星点 | **6 颗**，且关闭呼吸动效 |
| 动态星空 | **禁止**。不得使用 `requestAnimationFrame` 粒子 |
| DOM 星点节点 | **0** |

**空气层例外**：允许两处极弱椭圆渐变（不透明度 0.05–0.07）作为夜空大气，
但**不得形成紫蓝星云主体**。

## 5. 窗

- 形态：**窄高拱窗**（右侧，x 1286–1438 / y 286–652，viewBox `0 0 1440 900`）。
  窄高比例是为了与 1080px 内容栏共存而不被遮挡。
- 组成：石框（stroke 旧银 0.13）→ 窗内夜空渐变 → 远处月（r=11，不透明度 0.52 + 光晕）→
  8 颗窗内星 → 薄云 → 窗棂（竖 1 横 2）→ 窗台（顶缘一道黄铜 0.10）。
- 观星台场景：窗整体 `scale(1.34)`，扩大夜空占比，**但不变成宇宙**。
- 启封 / 魔女阁 / 详情场景：**窗关闭**（`display: none`）——这三个场景不需要夜空。

---

## 6. 书架

- 位置：左侧（x −40 → 318），可镜像为右侧柜体（魔女阁）。
- 结构：柜体背板 + 双立柱 + 顶檐 + 5 层板 + 确定性程序生成的书籍 + 底座。
- 书籍：约 50 本，宽度 8–25、高度 50–96，7 种深靛填充（`#101528`–`#252D58`），
  每本顶部一道 0.7px 旧银高光；每 5 本一道黄铜书脊线（0.22）。
- 倾斜书：约 7% 概率，倾斜 −4° ~ +4°。
- **对比度纪律**：书架只能作为「暗影轮廓」，不得亮过页面正文面板。

---

## 7. 黄铜器具

- **天球仪 / 星盘**：右下桌面，`translate(1300 762)`。
  外环 r=70（黄铜 0.20）、次环 r=56 / r=38、两个椭圆经纬环、中轴、
  中央黄铜点 r=4、支架与底座。
  **极慢旋转**：`.env-astro-ring` 180s 线性无限（仅主厅）。
- **窗台黄铜线**、**桌面暖光边**、**烛台黄铜底盘**——黄铜只做「边缘一道」，不做块面。
- 星盘的语义是**桌面仪器**，不是环绕玩家的宇宙轨道。

---

## 8. 烛光

- 组成：光晕椭圆（`url(#env-candle-glow)`，r 132×104）→ 烛台底盘（黄铜 0.22）→
  蜡身（羊皮纸色 0.16 + 左侧高光）→ 火苗（`#E6C687`）。
- 位置：左下桌面 `translate(146 806)`。
- 动效：光晕 `.env-flame-glow` 7.5s 呼吸；火苗 `.env-flame` 6.2s 轻微明灭。
- 移动端：光晕保留，动效关闭。

---

## 9. 桌面

- 实现：`.env-desk`（CSS，非 SVG），底部 20vh（移动端 14vh / <400px 11vh）。
- 渐变为暖木色 → 深棕，顶缘一道黄铜暖光横线。
- 作用：给出「近景」，让玩家感觉自己**坐在桌前**。
- 启封页桌面加高到 26vh（仪式需要更「近」的桌面）。

## 11. Mobile 简化

移动端（`max-width: 640px`）**切换为独立的简化场景** `.env-room-m`（viewBox `0 0 390 844`），
桌面端 `.env-room` 直接 `display: none`：

保留：
- 夜色渐变
- **1 个高窗暗影**（右上，被画面裁去一半）
- 5 颗窗内星 + 1 个很小的月
- 一角旧书架（不透明度 0.55）
- 1 处黄铜弧纹
- 1 支烛光

关闭：完整书架、天球仪、档案标签、栏杆、羊皮纸、所有缓慢动效、星点呼吸。

理由：390×844 下若完整塞入十几层装饰，会挤占 UI 并掉帧。

## 12. 动效限制

| 动效 | 周期 | 幅度 | 允许出现的场景 |
| --- | --- | --- | --- |
| 星点呼吸 `.env-sky` | 11s | 不透明度 0.82 ↔ 1.0 | home / observatory / unseal / quiet |
| 烛光呼吸 `.env-flame-glow` | 7.5s | 不透明度 0.72 ↔ 1.0，scale ≤ 1.06 | 全部（archive/detail 可保留） |
| 火苗明灭 `.env-flame` | 6.2s | 不透明度 0.70 ↔ 0.95 | 全部 |

**每页最多 1–2 类**环境动效。移动端全部关闭。
无 `requestAnimationFrame`，无 canvas，无粒子系统。

| 约束 | 值 / 做法 |
| --- | --- |
| 背景位图 | **0 张**（无 PNG / JPG / WebP 背景） |
| 背景 DOM 节点 | 1 个容器 + 2 个 SVG + 2 个 div（`.env-room-tint` / `.env-desk`）；星点走 CSS 渐变 |
| 星点 DOM 节点 | **0** |
| 新增网络资源下载体积 | **0 字节**（无新增图片 / 字体 / 独立 CSS 请求） |
| JS 产物 | 277,519 B（窗口 START_HEAD `bdd36ab`）→ **291,067 B**（**+13,548 B ≈ +13.2 KB**；gzip 97.81 KB） |
| CSS 产物 | 13,799 B → **20,863 B**（**+7,064 B ≈ +6.9 KB**；gzip 5.65 KB） |
| `dist/` 总体积 | 846 KB → **868 KB**（**+22 KB**，其中含本轮 3 处 Bug 修复的代码） |

## 15. 如何保证卡牌仍是视觉中心

四条硬纪律：

1. **中心留空**：星点与道具不进入画面中心 36%–64% 区域；书架与高窗只在左右边缘。
2. **不压卡牌**：桌柜类卡牌底板改用 `.card-btn::before` 的**深靛 matte plate**
   （radial-gradient，非发光卡框），保证暗牌（月亮 / 恶魔 / 宝剑九 / 部分圣杯宫廷）
   在深靛环境里仍有明确外轮廓。
3. **不加发光**：禁止给卡牌加发光边框、glow、bloom；暗牌问题只允许用
   `UI 容器 / card shadow / 局部底板 / outline contrast` 解决，**禁止改卡面 SVG**。
4. **归档背景最克制**：魔女阁（78 张全收集墙）的星点与道具全部降档，
   背景只提供「档案室」的世界观，不与 78 张争。

## 16. 背景验收 7 问

每次修改背景后，逐页回答：

| # | 问题 | 不合格处理 |
| --- | --- | --- |
| Q1 | 背景是否让我感觉处于魔女会 / 观星书房？ | 若否则加强实体道具 |
| Q2 | 是否仍然是实体空间，而不是宇宙？ | 若否则关闭星云 / 轨道类元素 |
| Q3 | 卡牌是否仍是第一视觉焦点？ | **若否则必须减背景** |
| Q4 | 文字是否仍可读？ | 否则加面板不透明度 |
| Q5 | 手机是否不过载？ | 否则减层 |
| Q6 | 有没有明显「幻想真境剧诗」共振？ | **若是则必须减背景** |
| Q7 | 有没有紫蓝星云化？ | **若是则必须减背景** |

Q3 = 否，或 Q6 / Q7 = 是 → **必须减背景，不允许辩解**。

## 17. 无障碍与语义

- 背景整层 `aria-hidden="true"` + `role="presentation"` + `pointer-events: none`；
- 不进入键盘焦点顺序，不影响 button label；
- 背景纯装饰，**不承担任何**按钮、路径、状态、功能语义；
- 主按钮 / 筛选器 / 详情返回 / 导航在新背景下的 `:focus-visible` 仍为 2px `var(--cyan)` 描边；
- `@media (prefers-reduced-motion: reduce)` 下：星点呼吸、烛光呼吸、火苗、薄云、
  天球仪旋转**全部关闭**（`animation: none !important`）。

## 18. 自检口径

> 把背景关掉，功能是否不受影响？

- **是** → 背景是环境层，合格（本项目当前状态）。
- **否**（背景元素开始承担按钮 / 路径 / 状态 / 功能）→ 做过头了，必须回退。

验收时可执行：

```bash
node .tools/gen.mjs beforeafter && node .tools/shots.mjs .tools/jobs-beforeafter.json
# 产物在 .audit-art/environment-before-after/（本地审计图，不入库）
```
