## 三、作品介绍（约 420 字，可直接用于报名表）

《夜泊江苏》是一款以江苏景点夜景为主题的 Web VR 卡牌收藏小游戏。玩家在「观星台」小游戏中收集星屑，用星屑启封一帧帧江苏夜色：全作共 78 张夜景卡，由 22 张「城章」（最具代表性的城市夜景地标）与 56 张「夜签」组成，「夜签」按灯影、水岸、山寺、城垣四大夜色系列收录，覆盖江苏 13 个设区市的经典景点——夫子庙秦淮画舫、拙政园夜园、瘦西湖五亭桥、金鸡湖东方之门、寒山寺枫桥、鼋头渚太湖灯塔、云龙湖苏公塔影……皆可收入册中。

作品的 VR 体验体现在两个层面：其一，每张卡牌采用 3D 视差渲染，随指尖倾斜产生景深与光晕，如持一张会发光的玻璃夜色；其二，收藏到的夜景卡可进入「全景夜游」模式，基于 Web 3D 全景环幕 360° 展现景点夜色，拖动或用手机陀螺仪即可环顾四周，身临其境地云夜游江苏。

技术上，作品基于 React 18 + TypeScript + Vite 构建，全部卡面与全景画面均为程序化生成的原创 SVG 视觉，无任何外部素材；本地优先设计，无需注册登录、无需 API Key，存档保存在本机并可导入导出；适配桌面与移动端。作品以轻量 Web 技术降低「云夜游」门槛，为「水韵江苏」夜间文旅提供了一种可传播、可收藏、可游玩的数字表达。

（超短版一句话：把 78 处江苏夜景做成会发光的 VR 卡牌，收集、把玩、身临其境地云夜游水韵江苏。）

## 四、创意来源（约 260 字）

作品的文化母题是张继的《枫桥夜泊》——「月落乌啼霜满天，江枫渔火对愁眠」，这是刻在中国人记忆里的江苏夜色第一名片；「夜泊」既是古人夜宿江畔的旅行方式，也是今天夜游经济的延续。近年来「水韵江苏」文旅品牌与夫子庙—秦淮河、金鸡湖、瘦西湖等夜游景区持续火爆，夜游打卡已成为年轻人认识一座城的主流方式。

在形式上，作品借鉴赏集换式卡牌的收集心理与博物馆文创「冰箱贴热」，把「到此一游」变成「此夜入册」：每一帧夜景都是一张可收藏、可把玩的数字明信片。而 Web 3D 与 CSS 3D 技术已足够成熟，让用户免下载 App 即可获得轻量 VR 体验——于是有了这台「装在浏览器里的江苏夜色收藏册」。

## 五、运行环境

**演示环境（评委体验）**
- 现代浏览器：Chrome / Edge / Firefox / Safari 最新版，无需安装任何插件；
- 纯前端应用：不需要服务器后端、不需要 API Key、不需要联网即可完整游玩（local-first，存档保存在浏览器 localStorage）；
- 移动端：iOS Safari 16+ / Android Chrome，支持触控拖动与陀螺仪全景环顾；响应式适配手机、平板、桌面。

**部署环境**
- `pnpm install && pnpm build` 产出纯静态 `dist/` 目录，可部署到任意静态服务器（Nginx / GitHub Pages / 对象存储）；
- 本地开发演示：Node.js ≥ 18（推荐 22 LTS），`pnpm install && pnpm dev` 后访问 http://localhost:5173。

**技术栈**
React 18 + TypeScript + Vite 6 + zustand；程序化 SVG 生成全部卡面与全景画面（原创视觉，无第三方素材）；CSS 3D 实现视差卡牌与全景环幕；Web Audio 合成音效；支持 `prefers-reduced-motion` 无障碍降级。

**硬件要求**
普通家用电脑或智能手机即可流畅运行，无独立显卡与 VR 头显要求。
